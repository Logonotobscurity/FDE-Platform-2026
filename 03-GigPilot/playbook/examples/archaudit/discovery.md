# Discovery brief — ArchAudit CCM

## Problem
Control evidence goes stale; teams cannot produce an audit pack with measurable time-to-evidence without manual screenshot hunts.

## Users / stakeholders
- GRC / compliance analyst: needs fresh evidence and pass/fail with rationale
- Security engineer: owns control pack and adapters
- Auditor: consumes the generated audit pack

## Success metric
Time-to-Evidence (median minutes from run start to summary.md) and Control Coverage %.

## Constraints
- Deterministic-first; no agent judgment in collection layer
- Offline-capable sample packs
- African operating environments (NG/KE packs later)
